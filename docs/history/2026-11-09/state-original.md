## Инженерные решения и ограничения

- `mcp_bridge.py` держит один stdio ClientSession; `mcp_call.py` обслуживает последовательную файловую очередь. Максимальное ожидание tool RPC — 600 секунд.
- Таймаут CLI не означает отмены удалённого исполнения. Сначала читать существующий ответ по ID; аварийные `processing` запросы не воспроизводить автоматически.
- Три vendor-правки сохранены в `colab-mcp-windows.patch`: IPv4 loopback, shield только startup task, конечный входящий WebSocket-лимит 16 MiB.
- Token/Origin-проверки не ослаблялись. Auth fragments и сырые приватные bridge logs исключены из пакета.
- Исторический Browser blocker требовал исходного браузерного контекста; сегодня штатный доступ восстановлен. Не приписывать прежний сбой LNA без доказательств и не обходить ограничения через CDP, профиль браузера или registry.
- После изменений notebook требуется явное сохранение и подтверждение интерфейса. RPC success отдельно от сохранения на Drive.
- Не занимать GPU ради повторной проверки уже завершённой цели, не менять тариф, не покупать ресурсы, не применять anti-idle.
