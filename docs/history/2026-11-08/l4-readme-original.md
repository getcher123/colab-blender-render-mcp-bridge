# Исторический тест на L4 — 8 ноября 2026

Эта папка содержит исходные файлы первого теста на NVIDIA L4, выполненного через интерфейс Colab до успешного A100-прогона через MCP.

- Исходный статус: `success_verified_gpu_user_a100_target_unmet`.
- `target_a100_met: false`.
- GPU: NVIDIA L4, Blender 4.5.15 LTS, CUDA.
- Рендер: 1600 × 1000, 96 samples, `render_seconds: 7.961`.
- Файлы `output/` и `install.json` скопированы из исторического корневого каталога проекта без изменений.

Эти файлы сохраняются для истории и не являются результатом проверки A100. Подтверждённые оригиналы A100 находятся в основном `output/` пакета. Время первого A100-прогона 490,448 с включает длительную начальную загрузку CUDA kernels, поэтому оно не является сопоставимым замером чистой скорости трассировки.
