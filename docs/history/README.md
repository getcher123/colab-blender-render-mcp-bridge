Текущий порядок работы задаётся **корневым [AGENTS.md](../../AGENTS.md)** и [state.md](../../state.md). Старые AGENTS намеренно переименованы, чтобы не создавать вложенную область действующих агентских инструкций. Старые абсолютные Windows/Colab пути и упоминания PID относятся к своему времени; не исполнять команды из истории как ready-made recovery.

В старых записях могут встречаться уже устранённые проблемы, неполный на тот момент экспорт, реконструированный run record и гипотезы причины ошибок. Финальный первичный A100 report и recovery evidence имеют приоритет для фактов результата. Описание прежнего browser/CDP действия не является разрешением повторять обходы текущего Browser context.

Точные SHA256 прежних файлов, их новые пути и характер адаптации перечислены в [source mapping](../../evidence/provenance/source_to_repository.json). Побайтные оригиналы всех семи гайдов сохранены в [полном исходном пакете](../provenance.md). Недоступные в исходном пакете материалы перечислены там же; они не восстановлены из предположений.
